H5 本地手动 Mock

实现文件位于 codex/legal/site/dev/，不属于 Cloudflare Pages public/ 发布目录。
启动：python3 codex/legal/site/dev/serve.py
打开：http://127.0.0.1:8765/start?consent=app&debug=1&mock=legal

调试窗口顶部可选择 Mock 协议（true）、Mock 活动（false）、真实接口（线上调试），点击“应用并重新开始”。
Mock 模式在本地返回固定路由，点击原有“继续”后进入协议或固定活动示例页。
所有模拟页面显示 MOCK 标识；不修改接口响应，不使用真实 Token、不请求业务接口、不读写活动缓存，也不写原生同意记录。
协议页浏览器按钮只展示模拟同意提示，无法验证 App 的原生回调。活动示例不是远程真实活动。
选择真实接口则打开现有 Cloudflare 线上调试入口，按原逻辑请求接口或读取活动缓存。
Mock 通过 URL 参数手动选择，不持久化、不添加审核识别规则，不提供线上覆盖策略开关。

开发服务器仅绑定 127.0.0.1，启动页在响应中临时注入开发脚本，不改 public/ 原文件；开发脚本自身也检查 loopback 主机。
正式 Pages 的 public/、iOS 代码、协议正文和已有活动缓存均未修改，未执行部署。
本地预览用于电脑浏览器，未在手机或模拟器运行 App。

验证：JavaScript 语法与 Python AST 检查通过；本地 HTTP 检查通过，启动脚本注入顺序正确、协议/活动资源可访问、开发文件和路径越界返回 404。
临时 Node VM 验证两种 Mock 分支均先等待继续再导航、控件可切换、显示标识、没有调用业务 fetch/身份接口/存储/原生授权。
非本地主机不启用开发脚本；真实接口选项跳转线上正常入口。git diff --check 通过。未执行浏览器视觉验收。
