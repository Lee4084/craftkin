一次性账号配置（目前尚未完成）：
1. 在 Apple Developer / App Store Connect 创建对应 com.echoskill.app 的标识和 App 记录，记录 App 的数字 Apple ID。
2. 在 Codemagic 添加 GitHub 仓库 Lee4084/craftkin，选择此工作流。
3. 在 Codemagic Code signing identities 中配置可匹配 com.echoskill.app 的 Apple Distribution 证书和 App Store provisioning profile，并包含证书私钥。此工作流不会把本机 huankeProfileDev 开发描述文件用于上传。
4. 创建环境变量组 app_store_credentials，包含：
   APP_STORE_APPLE_ID：App Store Connect 中该 App 的数字 Apple ID，不是 Bundle ID。
   APP_STORE_CONNECT_PRIVATE_KEY：App Manager 或相应授权的 App Store Connect API .p8 私钥正文，标记为 Secret。
   APP_STORE_CONNECT_KEY_IDENTIFIER：对应 Key ID。
   APP_STORE_CONNECT_ISSUER_ID：对应 Issuer ID。
5. 完成后触发 main 上的 ios-app-store-upload。API 触发还需有已授权的 Codemagic API Token 和项目 App ID。

密钥仅保存在 Codemagic Secret 或用户指定的本机凭据位置，不写入仓库或聊天。
现有本机 Apple 开发团队未替换；Codemagic 构建时通过分发描述文件设置正确的签名团队。
